Privacy

How this calculator handles data.

Calculations

This calculator runs in your browser. Calculation inputs and outputs are not sent to a calculation server.

Calculation history

Inputs and results are saved in this browser’s site storage using IndexedDB, with up to 20 calculations per calculator page. Use Clear history on that page or clear this site’s data in your browser to remove them. If persistent storage is unavailable, history is kept for the current tab only.

Clipboard

Copy buttons place the selected output on your device’s clipboard when you use them.

Hosting and external links

GitHub Pages serves the website and may process connection information as part of hosting it. Following a source or related-tool link opens a separate website with its own privacy practices.

Advertising and analytics

This version does not load advertising or analytics scripts.
